# Changelog

All notable user-visible changes to the Uptime Kuma TOS application package.

## 1.23.16-1 — 2026-11-15

### Added
- First release. Uptime Kuma (`louislam/uptime-kuma:1.23.16`, Docker Hub official image, unmodified)
  packaged as a TOS 7 Docker application, published on port 8144 and running
  as a non-root user (1000:1000).
- Persistent data is kept under `/Volume1/DockerAppData/uptimekumadocker/`.
